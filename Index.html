Fine-tune a big language model on a small GPU. Learn LoRA and QLoRA, size your run, and get a starter script.

LoRA

Instead of updating a huge weight matrix W (d × d), LoRA freezes it and learns two thin matrices A (r × d) and B (d × r). The output becomes W·x + (α/r)·B·A·x. With rank r = 16, you train under 1% of the parameters.

QLoRA

QLoRA does the same, but stores the frozen base model in 4-bit (NF4) and keeps the small adapters in 16-bit. Double quantization and paged optimizers cut memory further. A 7B model then fits in about 6 GB.

Starter script (QLoRA)

pip install transformers peft bitsandbytes trl datasets

import torch
from transformers import AutoModelForCausalLM, BitsAndBytesConfig
from peft import LoraConfig, get_peft_model

bnb = BitsAndBytesConfig(
    load_in_4bit=True,
    bnb_4bit_quant_type="nf4",
    bnb_4bit_use_double_quant=True,
    bnb_4bit_compute_dtype=torch.bfloat16)

model = AutoModelForCausalLM.from_pretrained(
    "mistralai/Mistral-7B-v0.1",
    quantization_config=bnb, device_map="auto")

cfg = LoraConfig(r=16, lora_alpha=32, lora_dropout=0.05,
    target_modules=["q_proj","k_proj","v_proj","o_proj"],
    task_type="CAUSAL_LM")
model = get_peft_model(model, cfg)
model.print_trainable_parameters()
# then train with trl.SFTTrainer on your dataset

For plain LoRA, drop the quantization_config. Built by Manjiri.
